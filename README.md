# CoreToolkit Development Site

Однофайловая интерактивная панель состояния разработки SolidWorks, КОМПАС-3D и Mathcad.

## Запуск

Откройте `index.html` в современном браузере. Внешние библиотеки и сетевые запросы не используются.

## Сохранение данных

Изменения карточек и история хранятся в локальном хранилище текущего браузера. Для резервной копии или переноса на другой компьютер используйте кнопки **Экспорт данных** и **Импорт** в интерфейсе.

Данные не синхронизируются между разными браузерами и устройствами: для общей командной базы потребуется серверное хранилище.

## Публикация

Для размещения на статическом хостинге используйте `index.html` как главную страницу сайта. Серверная часть для локального режима не требуется.
